# Speed-Camera Project with Web Interface

This project is an extension of the original [Speed-Camera](https://github.com/pageauc/speed-camera) project by Claude Pageau. The main goal of this project is to add a web interface that allows for remote control and monitoring of the Speed-Camera app on a Raspberry Pi.

## Overview

The Speed-Camera project is a powerful tool designed to monitor and capture images of objects moving above a specified speed threshold. This project extends the functionality by adding a web interface, enabling remote viewing of captured speed records and images through a browser.

The original Speed-Camera processing code remains Raspberry Pi focused. The web additions in this repository are intended to sit beside that code and read the SQLite database and media folders generated by `speed-cam.py`.

## Features

- Web interface for viewing speed-camera captures.
- JSON endpoint for reading recent speed records from `data/speed_cam.db`.
- Runtime folder structure for Raspberry Pi generated media and reports.
- Raspberry Pi camera workflow preserved from the original project.

## Raspberry Pi Runtime Notes

The camera process is still driven by `speed-cam.py` and configured through `config.py`.

By default, the project expects:

- SQLite database: `data/speed_cam.db`
- Captured images: `media/images`
- Recent images: `media/recent`
- Reports and graphs: `media/reports`, `media/graphs`, and `media/html`

Start and calibrate the camera application on the Raspberry Pi before expecting the web interface to show live capture data.

## Web Interface

Open the project in a browser through your web server, for example:

```text
http://<your-raspberry-pi-ip>/speed-camera/
```

The web page calls `getspeed.php`, which reads the latest rows from the Speed-Camera SQLite database and returns JSON for the browser display.
